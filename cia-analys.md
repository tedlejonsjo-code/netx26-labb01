Hot vald: ransomvare.

Hotet påverkar konfidentialitet genom att attakerarna kan använda den viktiga informationen, dom kan enkelt läsa och kopiera den till vad dom vill med vilket dom inte får. 

Hotet påverkar inte integritet så mycket för det blir låst men inte förändras inte. Det ändå som förändras med datan är att den blir låst.

Hotet påverkar tillgängligthet grovt genom att ransomattakerarna låser data och informationen bakom ett system så att dom inte går att använda när det behövs utan måste betala så i bästa fall så måste man vänta på att kunna återställa via en backup vilket tar tid.
